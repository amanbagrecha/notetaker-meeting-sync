# Meeting Notebook

A fused-render app that keeps one notebook page per day: the meetings you had (summary, what was discussed, decisions) and the to-dos you personally own from them. A background Claude task syncs meetings from Wispr Flow and Google Calendar; you can tick, add, edit or move to-dos, chat with a meeting's transcript, and turn hand-picked to-dos into Notion tickets.

Needs fused-render with Claude tasks enabled, plus the claude.ai Wispr Flow, Google Calendar and (for tickets) Notion connectors. All notebook data stays local in `.fused/data/`.
